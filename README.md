# 📊 Descriptive Analytics: Sales and Customer Analysis

## 📌 Project Overview

This project analyzes e-commerce sales and customer transaction data to understand revenue generation, customer satisfaction, regional performance, payment preferences, and product performance.

The dataset contains **100 transactions recorded between January 2024 and March 2024**.

The analysis focuses on identifying business trends and extracting meaningful insights from historical sales data.

4. The report can be used as a starting point for examining product-level sales performance.

* **Quantity Ordered:** Represents the number of product units ordered.
* **Sales:** Represents the sales amount.

### Numerical Values

### Insights

2. Grouping and organizing the information makes the report easier to read.
3. Product-line information helps users understand the categories of products being sold.
4. The total quantity ordered indicates the volume of orders represented in the report.
5. The total sales figure provides an overview of the sales represented in the report.

The attached output does not clearly align individual sales values with every country and product. Therefore, exact country-wise and product-line-wise rankings cannot be determined reliably from the supplied output.

### Conclusion

This practical demonstrates how grouped reports can organize sales data and make product and country information easier to review and analyze.

## Practical 4: Sales Cross-Tab by Region and Product Code

### Objective

To create a cross-tab report that compares sales across different regions and product codes.

### Explanation

A cross-tab presents information in rows and columns, making comparisons easier.

In this practical:

* **Rows:** Represent the regions APAC, NA, EMEA, and Japan.
* **Columns:** Represent different product codes.
* **Values:** Represent sales amounts for each region and product-code combination.

This format allows users to compare the sales of the same product across different regions.
